## Pitch

One-sentence pitch: Action Adventure Game where you cast spells using ISL to solve puzzles set in a fantasy environment.

Pillars: 
1. Solve by Experimenting
2. Learn by Playing
3. Cast by Signing

Player: Young Audience under 16 
Platform: Windows PC
Session Length: 25 Minutes

Non-goals: 
1. No VR / AR / XR
2. No multiplayer
3. No open world
