## Editor Preferences

To open new windows as tabs instead of new windows
Appearance -> Asset Editor Open Location -> Main Window

Turn off life coding
Live Coding -> Uncheck the tick box to Disable

## Project Settings

To set map and mode defaults
Project Settings -> Maps and Modes -> Default Game Mode
Project Settings -> Maps and Modes -> Editor Startup Map & Game Default Map
